# Freedom website

Static website for Freedom by Yakon Design.

## Live site

GitHub Pages: `https://yakon-dot.github.io/freedom-website/`

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Contents

- `index.html` — homepage
- `css/styles.css` — shared styles
- `privacy/` — Privacy Policy
- `terms/` — Terms of Use
- `support/` — Support
- `assets/` — brand logo
